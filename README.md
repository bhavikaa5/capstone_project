# Nifty 50 Regime-Aware Price Forecasting — Capstone (Group 17)

Regime-conditioned forecasting on 15-minute Nifty 50 index data: an HMM labels
the market regime, and three competing deep architectures are trained and
compared under that conditioning.

```
Nifty 50 15-min OHLC
        │
        ▼
Feature engineering ── RSI · MACD · ATR · ADX · Bollinger
        │
        ▼
HMM regime labelling ── bull · bear · sideways · high-vol
        │
        ├──────────────┬──────────────┐
        ▼              ▼              ▼
CNN-BiLSTM-Attention  LSTM       Transformer
        └──────────────┴──────────────┘
        │
        ▼
Optuna (TPE) hyperparameter search
        │
        ▼
Evaluate & select ── classification + trading metrics
        │
        ▼
Live validation (Kite Connect) ──► Integrity dashboard
```

## Data

NSE Nifty 50 **index**, 15-minute bars, 09:15–15:15 IST (25 bars/session).

| | Train | Test |
|---|---|---|
| Range | 2015-04-23 → 2024-04-30 | 2024-05-02 → 2025-04-08 |
| Clean bars | 55,586 | 5,810 |
| Sessions | 2,226 | 234 |

The split is strictly chronological with no overlapping timestamps — asserted in
code, not assumed.

**The source data has no volume column**, despite the pipeline diagram saying
OHLCV. All five indicator blocks need only OHLC and are unaffected, but OBV,
VWAP deviation and volume-confirmed breakouts are unavailable.

## Things that are easy to get wrong here

Each is documented with its evidence in `docs/`:

- **Duplicate boundary days.** The vendor CSVs were stitched from overlapping
  monthly chunks; 74 train dates appear twice. The copies share a `close` but
  the second one's opening bar is ~95 index points off the previous session.
  Keep the first. ([docs/11](docs/11_Data_Step1.md))
- **Price-denominated features must not reach a model.** Nifty triples across
  the training window, so raw MACD and ATR carry the price level as a hidden
  trend. Call `model_feature_columns()` rather than hand-listing columns.
  ([docs/13](docs/13_Features_Step2.md))
- **Bollinger needs `ddof=0`.** pandas defaults to `ddof=1`, which widens every
  band by 2.6% against every charting package.
- **ADX is unsigned** — a crash and a rally both read ~40. Pair it with
  `di_spread`.
- **Warm-starting, not leakage.** The test split is seeded from the last 1,250
  train bars, which are then discarded. Past into future is correct; the code
  raises if the seed overlaps the target.
