## OBJECTIVE

**Develop an AI-based market regime detection system for the Nifty 50 index using historical OHLCV and technical indicator data.**

1. **Regime Labeling & Model Training:** Generate market regime labels using a Hidden Markov Model (HMM) and train deep learning models on time-ordered historical data.

2. **Model Development & Comparison:** Implement and compare CNN-BiLSTM-Attention, LSTM, and Transformer models for market regime classification.

3. **Hyperparameter Optimization:** Optimize the models using hyperparameter tuning to improve regime detection accuracy and trading performance.

4. **Live Validation:** Validate the best-performing model on live 15-minute Nifty 50 data using both classification and trading performance metrics.
